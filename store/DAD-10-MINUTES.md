# Dad — 10 minutes, everything is prepared. Sam did the rest.

Go to appstoreconnect.apple.com → My Apps → Quizard: SSAT prep → version 1.0 page.

1. DESCRIPTION + PROMO TEXT + KEYWORDS
   → open LISTING.md (this folder), copy each section into its matching box.

2. SCREENSHOTS
   → drag the 6 PNGs from this folder into the iPhone screenshots strip,
     in filename order (1-home first).

3. APP REVIEW INFORMATION (bottom of page)
   → open REVIEW-NOTES.md, paste it into "Notes"
   → demo account fields: QuizardDemo / WizardHat2026
   → your name, email, phone in the contact fields.

4. BUILD section → ⊕ → select 1.0 (2).
   (The app icon appears by itself when you do this — it rides in the build.)

5. Top right: Add for Review → Submit for Review.

Done. Status flips to "Waiting for Review." Apple usually answers in 1–3 days.
